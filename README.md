# Проект получения информации по имени человека

Краткое описание проекта:  
 * Rest end point доступен на [http://localhost:8080/info/{name}](http://localhost:8080/info/ivan)
 * Задача — предоставить информацию по имени
 * При формировании ответа обращается к другим сервисам
 * Количество запросов с одного IP должно быть ограничено (rate-limit)  

Проект состоит из двух модулей:  
* [app](app)
* [rate-limiter-starter](rate-limiter-starter)

## app
Модуль самого приложения с эндпойнтом для предоставления информации о запрошенном имени

## rate-limiter-starter
Разработанный **стартер** для ограничения числа запросов (rate-limit).  
Подключается в модуль приложения [app](app).  
При подключении стартера, можно помечать методы аннотацией [@RateLimiter](rate-limiter-starter/src/main/java/com/alextim/ratelimiter/annotation/RateLimited.java).


**Пример запроса**

```bash
curl http://localhost:8080/info/aleksey
```

**Ответ**

```
{
    "Имя":"aleksey",
    "Пол":"мужской (вероятность : 99.0 процентов)",
    "Возраст":"47 лет (средний)"
}
```
